# E-Commerce SQL Data Analysis (Project 3)

**Author:** Ajiboye Opeyemi Oluwasijibomi  
**Database:** `sql_project` | **Table:** `ecom_orders` (1,200 records)  
**Tool Used:** MySQL Workbench  

---

## 📌 Executive Summary
This project analyzes 1,200 e-commerce transactions to evaluate high-value delivered orders, product category revenue, fulfillment statuses for orders placed from 2024 onwards, and marketing referral channel performance.

---

## 🔍 SQL Queries & Findings

### Query 1: High-Value Delivered Orders
- **Objective:** Filter for delivered orders exceeding $1,000.
- **Key Insight:** Identified 142 high-value orders over $1,000.

### Query 2: Product Revenue Performance
- **Objective:** Calculate total orders, units sold, average price, and revenue per product.
- **Key Insight:** **Chair** generated the highest total revenue ($195,620.11 across 185 orders).

### Query 3: Order Status Breakdown (2024 Onwards)
- **Objective:** Summarize post-2024 order volume and gross value by status.
- **Key Insight:** **Returned** orders held the highest order volume (145 orders).

### Query 4: Marketing Referral Channels
- **Objective:** Evaluate net revenue for fulfilled orders across acquisition channels.
- **Key Insight:** **Instagram** drove the highest net revenue ($108,246.78).
